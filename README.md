# 🇵🇱 Antigravity Polski — Spolszczenie + Poradnik

**Pełne spolszczenie** modułów **Agent Manager** i **Ustawień** w [Google Antigravity IDE](https://antigravity.google), wzbogacone o rozbudowane opisy i interaktywny poradnik po polsku.

---

## ✨ Co zawiera (v0.5)

| Panel | Opis |
|-------|------|
| **Spolszczone Ustawienia** | Wszystkie opcje Antigravity przetłumaczone na polski z tooltipami i szczegółowymi wyjaśnieniami |
| **Menedżer Agentów PL** | Interaktywna mapa interfejsu Agent Managera, słownik EN→PL (40+ terminów), poradnik „Jak zacząć" |
| **Ściągawka** | Skróty klawiszowe, gotowe konfiguracje JSON do skopiowania, szablony reguł i workflow |
| **Roadmapa** | Krok po kroku: jak stworzyć własne rozszerzenie dla Antigravity/VS Code |

## 📸 Jak otworzyć

1. Naciśnij `Ctrl+Shift+P` (paleta poleceń)
2. Wpisz **Antigravity PL**
3. Wybierz dowolny panel

Lub kliknij ikonę 🌐 na pasku stanu (na dole okna).

## ⚙️ Wymagania

- Google Antigravity IDE **lub** VS Code / VS Code Insiders v1.85+
- Brak dodatkowych zależności

## 🔧 Ustawienia rozszerzenia

| Ustawienie | Opis | Domyślna wartość |
|---|---|---|
| `antigravityPL.showStatusBar` | Pokaż ikonę 🌐 na pasku stanu | `true` |
| `antigravityPL.autoOpenGuide` | Otwórz przewodnik przy pierwszym uruchomieniu | `true` |
| `antigravityPL.tooltipLanguage` | Język tooltipów | `pl` |
